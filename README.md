# Apartment Price Prediction API 🏠

RESTful API сервис для предсказания рыночной стоимости квартир на основе машинного обучения (Linear Regression). Проект разработан на Python с использованием FastAPI.

## 🚀 Стек технологий
* **Python 3.10+**
* **FastAPI** (веб-фреймворк и автоматическая документация Swagger)
* **Scikit-learn** (машинное обучение)
* **Pandas / Joblib** (обработка данных и сохранение модели)
* **Uvicorn** (ASGI-сервер)
